# Collection101
A collection of my APCSP projects

🎰 Project 1: Slots Game
This program simulates a casino‑style slot machine where players deposit tokens, spin weighted reels, and earn payouts for matching symbols. It also includes a simulation mode that calculates long‑term house profit.

🧙‍♂️ Project 2: Hogwarts Sorting Hat
This program assigns users to a Hogwarts house, giving well‑known characters their canonical houses while sorting all other names randomly. It includes a short animated delay to mimic the Sorting Hat experience.

🟩 Project 3: Wordle
This is a Wordle‑style guessing game where players have six attempts to guess a secret five‑letter word, receiving emoji‑based feedback for accuracy. It handles repeated letters correctly and selects a random word each round.

📋 Project 4: To‑Do List Manager
This command‑line app lets users add tasks, mark them as completed, remove items, and track progress in real time. It includes input validation and a clear menu system for easy navigation.

🐢🐇 Project 5: Tortoise vs Hare Race Simulation
This program simulates a race between a tortoise and a hare using randomized movement and a sleep mechanic for the hare. The race continues until one competitor reaches the finish line, and the program announces the winner.

**🚀 Purpose of This Portfolio**
This repository serves as a showcase of my Python skills, demonstrating my understanding of variables, loops, conditionals, functions, randomness, and user interaction. It provides a clear record of my programming experience for future academic or professional opportunities.
